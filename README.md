# 🎬 Movie Recommendation Website

A simple movie recommendation website built with HTML, CSS, and JavaScript.

## Features

- Filter recommendations by mood
- Filter recommendations by genre
- Get a random movie suggestion from matching results
- Friendly and responsive UI
- Built with plain HTML/CSS/JS (no frameworks)

## Files

- `index.html` – Page structure and movie recommendation UI
- `style.css` – Styling for the website
- `script.js` – Recommendation logic and movie dataset

## How to Run

1. Clone or download this repository.
2. Open `/home/runner/work/Snake-Game/Snake-Game/index.html` in your browser.
3. Choose a mood and genre.
4. Click **Recommend a Movie**.
